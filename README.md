# Awesome Bluesky 🛠️

[Bluesky](https://github.com/bluesky-social/) is an open-source microblogging platform powered by the [AT Protocol](https://atproto.com/). This protocol enables the creation of powerful third-party tools, enlisted here for easy reference.

This list is for end-user-facing software and tools that can run "out of the box" without programming knowledge.

> **⚠️ Security Note:** Always use an **App Password** for third-party apps, never your main account password!

---

| [TrackBlue](https://track.blue/) | Provides robust social media management with post scheduling, engagement tracking, and powerful CRM tools for audience management. |

## Account & Follower Management

These tools help you manage your network, track your follower growth, and curate your block/mute lists.

| Tool | Description |
| :--- | :--- |
| [Tracker - Manager for Bluesky](https://linktr.ee/bluesky.tracker) | A mobile app for real-time tracking and detailed management of your followers and followings. |

| [TipTopBot](https://tiptopbot.com) | Lists followers or follows for any Bluesky handle, with the ability to export the data to a CSV file. |

| [ClearSky Search Tool](https://clearsky.app/) | A multi-function tool to see who is blocking you, who a user is blocking, and to look up user DIDs. |

| [Bluesky Follower Explorer](https://bluesky-followers.advaith.io/) | An alternative client feature that lets you analyze the follower relationships of the accounts you follow. |
| [Bluesky network analyser](https://bsky-follow-finder.theo.io/) | Helps you discover accounts that are followed by people you follow, but that you don't follow yet. |
